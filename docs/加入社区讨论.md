# 加入社区

欢迎分享 TLog 的使用经验、集成问题和改进建议。

## 问题反馈

代码问题建议提交到 [GitHub Issues](https://github.com/dromara/TLog/issues) 或 [Gitee Issues](https://gitee.com/dromara/TLog/issues)。请附上版本信息、日志配置、调用方式和可运行的最小示例；提交前移除密码、令牌与业务敏感数据。

如果正在升级 2.0，先阅读[升级指南](/guide/upgrade)和[兼容性说明](/guide/compatibility)。

## 开源协作

TLog 专注于日志标记与上下文传播，并与现有日志平台协作。功能建议、文档贡献和可重复的验证结果都很有价值。
