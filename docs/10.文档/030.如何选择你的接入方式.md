# 如何选择你的接入方式

TLog 2.0 只有日志配置文件接入方式。先加入适配当前应用的依赖，再配置日志标签输出；不再按 javaagent、字节码注入和日志适配器三种方式选择。

| 应用场景 | 接入步骤 |
| --- | --- |
| Spring Boot Servlet / WebFlux | 加入对应 starter，保留应用自己的 Web 和日志依赖，配置 MDC 或日志适配器 |
| Spring Boot Feign / Dubbo / 网关 | 加入对应 TLog starter；如果应用也有 HTTP 入口，一并加入 Web 适配 |
| 非 Boot Spring 应用 | 使用实现模块，手工声明 TLog 组件，见[Spring 项目接入](/pages/d81b62/)和[其他配置](/pages/8110af/) |
| 纯 Java 客户端或任务 | 使用实现模块，手工建立/清理入口上下文，安装客户端拦截器并包装执行器 |
| 外置 Servlet 容器 | 注册与容器命名空间匹配的 Filter，并配置 REQUEST、ASYNC、ERROR 和 asyncSupported |

## 日志输出选择

- 希望把标签放在固定位置：使用 MDC 的 `%X{tl}`。`tl` 是完整标签，也可单独输出 `tlogTraceId` 和 `tlogSpanId`。
- 希望保留已有 TLog encoder/layout/converter：继续使用[日志适配器](/pages/5223de/)。不要同时让两套配置重复输出同一标签。
- 使用日志异步 appender：让日志事件在业务线程捕获 MDC，或使用 TLog 异步适配器。业务线程池的透传是另一件事，仍需按[异步文档](/pages/a69e1d/)配置。

::: warning 从 1.x 升级
删除 `-javaagent:tlog-agent.jar` 和 `AspectLogEnhance.enhance()`。这两种入口在 2.0 中已移除，不是关闭某个配置后还能继续使用的功能。步骤见[升级指南](/guide/upgrade)。
:::
