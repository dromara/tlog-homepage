# 自定义Convertor

自定义转换器接收方法的参数数组，返回要加入标签的文本：

```java
import com.yomahub.tlog.core.convert.AspectLogConvert;

public class PersonLabelConvert implements AspectLogConvert {
    @Override
    public String convert(Object[] args) {
        if (args.length == 0 || args[0] == null) {
            return null;
        }
        Person person = (Person) args[0];
        return "PERSON(" + person.getId() + ")";
    }
}
```

在 Spring Bean 的方法上使用：

```java
import com.yomahub.tlog.core.annotation.TLogAspect;

@TLogAspect(convert = PersonLabelConvert.class)
public void process(Person person) {
    log.info("处理人员记录");
}
```

假设 id 为 `31`，日志为：

```text
<0.2><demo-request-001> [PERSON(31)] 处理人员记录
```

## 实例与异常行为

转换器由 TLog 通过无参构造创建，并按类型缓存复用。转换器类必须是 public（嵌套类须为 public static），并提供 public 无参构造；把实现写成无状态或线程安全的类。它不是通过 Spring 创建的业务 Bean，不应依赖字段注入自动完成。

返回 null 或空白文本时不追加该部分。转换器抛出的异常会被记录，转换器标签被跳过；这与参数表达式失败会抛出 `TLogCustomLabelExpressionException` 的行为不同。

转换器可以与 `str` 和 `value` 同时使用，顺序为固定文本、转换器结果、参数表达式；再按 `joint` 和 `pattern` 组合。
