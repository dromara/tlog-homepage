# 多个数值

`value` 可以声明多个表达式，按声明顺序输出；默认连接符是逗号。

```java
@TLogAspect({"id", "name"})
public void process(String id, String name) {
    log.info("处理用户记录");
}
```

传入 `NO1234` 和 `jenny` 时：

```text
<0.2><demo-request-001> [id:NO1234,name:jenny] 处理用户记录
```

返回 null 或空白文本的表达式结果不会加入标签。非基础对象结果会序列化为 JSON；用于日志的字段应尽量简单，避免输出不必要的大对象或敏感值。

方法返回或抛出业务异常后恢复外层标签。自定义连接符和外围格式见[下一页](/pages/1d4247/)，代理调用和参数名条件见[业务标签说明](/pages/9c287d/)。
