# 点操作符

表达式可以通过点操作读取方法参数中的 Bean 属性或 Map 项。例如 `person` 提供 `getId()`、`getAge()` 和相应的嵌套 getter：

```java
@TLogAspect({"person.id", "person.age", "person.company.department.dptId"})
public void process(Person person) {
    log.info("处理人员记录");
}
```

日志示意：

```text
<0.2><demo-request-001> [person.id:31,person.age:25,person.company.department.dptId:80013] 处理人员记录
```

传入 Map 时，可以按同样方式读取键；数组或列表下标由表达式引擎处理，使用前应覆盖对应类型和越界情况的测试。

## JSON 输入

普通 `String` 不会因为内容是 JSON 就自动转换为可访问属性的对象。先在业务入口把 JSON 解析为 Bean 或 Map，再传给带注解的方法。2.0 不再依赖 fastjson 1.x，因此不要依赖旧 `JSONObject` 类型作为 TLog 的必备 API。

参数名仍需要可被反射或 Spring 发现。空链路、缺失属性和非法表达式应在应用测试中处理；表达式执行失败会抛出 `TLogCustomLabelExpressionException`，不会自动改成一段空标签继续业务。

复杂取值或需要明确的空值策略时，可以改用[自定义转换器](/pages/7183b3/)。
