# 业务自定义标签能干嘛

`@TLogAspect` 可以把订单号、任务编号等业务字段临时追加到当前日志标签中，方便检索某段方法执行过程。

```java
@TLogAspect(value = "orderId", str = "order")
public void process(String orderId) {
    log.info("开始处理");
}
```

传入 `ORD-42` 时，标签示意为：

```text
<0><demo-request-001> [order,orderId:ORD-42] 开始处理
```

## 生效范围

这是 Spring AOP 方法切面。对象需要由 Spring 管理，调用需经过代理；同一个对象内部的直接自调用不会自动触发该切面。2.0 支持 JDK 代理解析实现方法上的注解。

标签在方法执行期间追加到 `AspectLogContext` 和 MDC `tl`，方法正常返回或抛出业务异常后恢复原标签；嵌套方法返回后恢复到外层标签。没有 trace 上下文时也可输出业务标签，但注解本身不会创建 traceId。

表达式依赖可发现的参数名，应用构建应保留 `-parameters` 信息。需要稳定输出但不使用参数名时，可以选择固定文本或自定义转换器。

## 异步方法的边界

在带标签的方法中提交任务时，受支持的执行器可以捕获提交时的标签。返回 `Mono`/`Flux` 的方法，其注解作用域只覆盖方法调用和 Publisher 组装，不会自动延长到后续异步订阅；不要把同步 AOP 标签生命周期当成整个响应式流的生命周期。
