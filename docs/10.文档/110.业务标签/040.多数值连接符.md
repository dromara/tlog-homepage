# 多数值连接符

`joint` 决定多个标签部分之间的连接符，`pattern` 中的 `{}` 放置连接后的内容。

```java
@TLogAspect(value = {"id", "name"}, pattern = "<-{}->", joint = "_")
public void process(String id, String name) {
    log.info("自定义标签格式");
}
```

传入 `NO1234` 和 `jenny` 时：

```text
<0.2><demo-request-001> <-id:NO1234_name:jenny-> 自定义标签格式
```

默认 `joint` 是 `,`，默认 `pattern` 是 `[{}]`。固定文本、转换器返回值和参数表达式都会参与同一次连接。

这个 `pattern` 只改变当前方法追加的业务标签，不会改变 `tlog.pattern` 的全局 trace/span 标签模板，也不会修改传播头。
