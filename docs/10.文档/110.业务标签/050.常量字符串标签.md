# 常量字符串标签

`str` 用于追加固定文本，不依赖方法参数名：

```java
@TLogAspect(str = "inventory-check")
public void checkInventory() {
    log.info("检查库存");
}
```

日志示意：

```text
<0.2><demo-request-001> [inventory-check] 检查库存
```

也可以与参数表达式组合：

```java
@TLogAspect(str = "inventory-check", value = "sku")
public void checkInventory(String sku) {
    log.info("检查库存");
}
```

传入 `SKU-42` 时追加 `[inventory-check,sku:SKU-42]`。固定文本先于转换器和参数表达式输出。

标签只在经 Spring 代理拦截的方法作用域内生效，方法结束后恢复外层标签。若在该作用域提交异步任务，使用[支持上下文传播的执行器](/pages/a69e1d/)。
