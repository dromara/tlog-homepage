# 简单例子

在 Spring Bean 的方法上声明参数表达式，并从另一个 Bean 通过代理调用：

```java
import com.yomahub.tlog.core.annotation.TLogAspect;

@TLogAspect("id")
public void process(String id) {
    log.info("开始处理");
    log.info("处理完成");
}
```

假设 `id` 为 `NO1234`，当前 trace/span 为 `demo-request-001` / `0.2`，日志示意为：

```text
<0.2><demo-request-001> [id:NO1234] 开始处理
<0.2><demo-request-001> [id:NO1234] 处理完成
```

表达式结果按 `表达式:值` 输出，不是只输出 `[NO1234]`。业务标签前与原标签之间有一个空格。方法结束后，调用方的后续日志恢复为原来的 `<0.2><demo-request-001>`。

应用编译需要保留参数名，例如 Maven compiler 的 `<parameters>true</parameters>`。表达式取值失败会抛出 `TLogCustomLabelExpressionException`，应在测试中覆盖实际参数和空值路径。

线程池中的日志使用[执行器传播](/pages/a69e1d/)，不建议用未经包装的 `new Thread` 示例来证明 MDC 也能自动继承。
