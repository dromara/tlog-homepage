# MDC模式下log4j2的配置

TLog 2.0 入口会把完整标签写入 MDC `tl`。Log4j2 可以使用标准 `%X{tl}`；旧文档中的 `%TX{tl}` 是保留的 TLog 插件别名，并非唯一写法。

设置 `tlog.mdc-enable=true` 后，使用：

```xml
<Configuration status="WARN">
    <Appenders>
        <Console name="CONSOLE" target="SYSTEM_OUT">
            <PatternLayout pattern="%d{HH:mm:ss.SSS} %-5level %X{tl} [%thread] %msg%n"/>
        </Console>
    </Appenders>
    <Loggers><Root level="info"><AppenderRef ref="CONSOLE"/></Root></Loggers>
</Configuration>
```

只需要 traceId 和 spanId 时可以分别使用 `%X{tlogTraceId}`、`%X{tlogSpanId}`。完整 `tl` 还会包含模板中的其它字段和当前方法的业务标签。

已有 `%TX{tl}` 配置可以保留，但需要确保打包时保留 TLog 的 Log4j2 插件资源。不要同时输出 `%X{tl}`、`%TX{tl}` 和带标签的消息前缀，造成重复。

日志异步使用事件的上下文快照；业务异步使用执行器装饰。无需为了异步 appender 依赖新线程继承属性。配置与边界见[Log4j2 适配](/pages/8d5538/)和[MDC 异步](/pages/348797/)。
