# MDC模式的说明

MDC 允许把标签放在日志行的指定位置，例如放在级别后、消息前：

```text
%d{HH:mm:ss.SSS} %-5level %X{tl} %msg%n
```

TLog 入口写入以下字段：

| MDC key | 内容 |
| --- | --- |
| `tl` | 按 `tlog.pattern` 生成的完整标签，方法级业务标签也会临时追加在此 |
| `tlogTraceId` | 当前 traceId |
| `tlogSpanId` | 当前 spanId |
| `currIp` | 当前节点 IP |
| `preIp` | 上游 IP |
| `preIvkHost` | 上游主机名 |
| `preIvkApp` | 上游应用名 |

## 与消息前缀适配器配合

使用普通 encoder/layout 的 `%X{tl}` 即可读取入口写入的标签。可以设置 `tlog.mdc-enable=true`，让保留的 TLog 消息适配器不再重复追加标签。

`mdc-enable` 不是“是否写入 MDC”的开关；设置为 false 不会关闭或清空这些字段。只有已经建立上下文的日志才有值。

配置示例：[logback](/pages/eea781/)、[Log4j2](/pages/1cc569/)、[旧 Log4j](/pages/1847d5/)。2.0 已删除 agent/字节码接入，因此不再存在按三种入口划分的 MDC 功能差异。

## 业务异步与异步日志

MDC 通常属于当前业务线程。业务任务换线程时，使用 Spring 自动装饰或 `TLogExecutors.wrap` 同时传播 TLog 和 MDC；日志事件进入异步队列时，则由 appender 保留事件快照。详细说明见[MDC 异步](/pages/348797/)。
