# MDC模式下log4j的配置

仍使用 Log4j 1 API 的应用可通过 `%X{tl}` 读取 TLog 写入的 MDC。SLF4J 必须绑定到应用正在使用的 Log4j 实现。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE log4j:configuration SYSTEM "log4j.dtd">
<log4j:configuration xmlns:log4j="http://jakarta.apache.org/log4j/">
    <appender name="CONSOLE" class="org.apache.log4j.ConsoleAppender">
        <layout class="org.apache.log4j.PatternLayout">
            <param name="ConversionPattern" value="%d{HH:mm:ss,SSS} %-5p %X{tl} [%t] %m%n"/>
        </layout>
    </appender>
    <root><priority value="info"/><appender-ref ref="CONSOLE"/></root>
</log4j:configuration>
```

Spring Boot 应用可同时设置：

```properties
tlog.mdc-enable=true
```

已有 `AspectLog4jPatternLayout` 也支持 `%X{tl}`，并会识别 MDC 输出模式。无论采用哪种 layout，都应只输出一次完整标签。

使用日志异步队列时，输出的是事件保存的 MDC；业务线程池仍需[单独透传](/pages/348797/)。本页保留旧框架兼容说明，不代表本轮已经完成 Log4j 1 的完整跨进程验收。
