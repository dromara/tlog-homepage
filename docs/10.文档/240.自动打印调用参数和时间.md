# 自动打印调用参数和时间

使用 Spring Boot 自动配置时，可以开启 Servlet Web、Dubbo/Dubbox 对应入口的参数与耗时日志：

```yaml
tlog:
  enable-invoke-time-print: true
```

默认值为 false，旧 `tlog.enableInvokeTimePrint` 写法仍可通过 Spring relaxed binding 绑定。该开关不等于为任意 HTTP 客户端、MQ 或所有方法自动测量耗时。

## 输出内容

Servlet 日志包含 URL、请求参数映射和耗时；Dubbo/Dubbox 日志包含接口、方法、调用参数和耗时。例如：

```text
<0><trace-example> [TLOG]开始请求URL[/orders],参数为:{"page":["1"]}
<0><trace-example> [TLOG]结束URL[/orders]的调用,耗时为:12毫秒
```

以上仅说明格式，数值不是性能测试结果。Servlet 参数映射不等于完整 JSON body 或上传文件内容；TLog 不会为了这个开关自动复制任意请求体。

2.0 在关闭耗时打印时不为日志读取请求参数。默认 Filter 在字符编码过滤器后执行，避免中文表单因提前解析而改变。参数序列化采用容错输出；上下文清理与结束日志分开处理，防止失败后污染后续请求。

Servlet 异步请求可能经过多个 dispatch。这里的过滤器计时表示各次过滤器调用范围，不应作为完整异步业务耗时或 APM span 时长使用。

## 普通 Spring 配置

```xml
<bean id="tlogSpringAware" class="com.yomahub.tlog.spring.TLogSpringAware"/>
<bean class="com.yomahub.tlog.spring.TLogPropertyInit" depends-on="tlogSpringAware">
    <property name="enableInvokeTimePrint" value="true"/>
</bean>
```

日志将包含业务参数，应用需要按自己的日志字段策略决定是否开启。准确的计时覆盖范围和部署版本应结合[实际示例](/guide/examples)验证。
