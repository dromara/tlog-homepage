# Log4j框架适配器

本页用于仍使用 Log4j 1 API 的旧应用。TLog 保留相应适配类；新应用通常直接使用自身框架提供的 logback 或 Log4j2。应用必须提供日志实现，并让 SLF4J 绑定到同一实现。

## 同步日志

在原来的 appender 中使用 `AspectLog4jPatternLayout`，`%m` 会在有 TLog 上下文时输出标签和消息：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE log4j:configuration SYSTEM "log4j.dtd">
<log4j:configuration xmlns:log4j="http://jakarta.apache.org/log4j/">
    <appender name="CONSOLE" class="org.apache.log4j.ConsoleAppender">
        <layout class="com.yomahub.tlog.core.enhance.log4j.AspectLog4jPatternLayout">
            <param name="ConversionPattern" value="%d{HH:mm:ss,SSS} %-5p [%t] %m%n"/>
        </layout>
    </appender>
    <root><priority value="info"/><appender-ref ref="CONSOLE"/></root>
</log4j:configuration>
```

此示例使用消息前缀，不要另外启用 `tlog.mdc-enable=true` 却又没有输出 `%X{tl}`，否则会抑制前缀。

## 异步日志

使用消息前缀方式时，让 TLog appender 在业务线程把标签写入事件，目标 appender 使用普通 layout：

```xml
<appender name="TARGET" class="org.apache.log4j.ConsoleAppender">
    <layout class="org.apache.log4j.PatternLayout">
        <param name="ConversionPattern" value="%d{HH:mm:ss,SSS} %-5p [%t] %m%n"/>
    </layout>
</appender>
<appender name="ASYNC" class="com.yomahub.tlog.core.enhance.log4j.async.AspectLog4jAsyncAppender">
    <appender-ref ref="TARGET"/>
</appender>
<root><priority value="info"/><appender-ref ref="ASYNC"/></root>
```

将上述片段放入应用的 `log4j:configuration` 中。另一种选择是使用 [MDC 配置](/pages/1847d5/)输出事件中保存的标签。

日志异步不等于业务线程透传，线程池仍按[异步文档](/pages/a69e1d/)配置。当前跨进程 demo 没有把 Log4j 1 运行结果计入已实测矩阵，详见[兼容性](/guide/compatibility)。
