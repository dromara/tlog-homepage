# Logback框架适配器

logback 可以采用 TLog 消息前缀适配器，也可以使用普通 encoder 的 `%X{tl}`。下面先介绍保留的适配器方式；MDC 方案见[专门页面](/pages/eea781/)。

## 同步日志

把原有 appender 的 encoder 改为 `AspectLogbackEncoder`：

```xml
<configuration>
    <appender name="CONSOLE" class="ch.qos.logback.core.ConsoleAppender">
        <encoder class="com.yomahub.tlog.core.enhance.logback.AspectLogbackEncoder">
            <pattern>%d{HH:mm:ss.SSS} %-5level [%thread] %logger{36} - %msg%n</pattern>
        </encoder>
    </appender>
    <root level="INFO"><appender-ref ref="CONSOLE"/></root>
</configuration>
```

已有基于 layout 的配置也可使用 `com.yomahub.tlog.core.enhance.logback.AspectLogbackLayout`。当没有启用 MDC 标签输出时，适配器会在消息前追加当前标签。

## 异步日志

使用消息前缀时，让 TLog appender 在日志入队前记录标签；目标 encoder 使用普通实现：

```xml
<configuration>
    <appender name="TARGET" class="ch.qos.logback.core.ConsoleAppender">
        <encoder><pattern>%d{HH:mm:ss.SSS} %-5level [%thread] %msg%n</pattern></encoder>
    </appender>
    <appender name="ASYNC" class="com.yomahub.tlog.core.enhance.logback.async.AspectLogbackAsyncAppender">
        <queueSize>2048</queueSize>
        <discardingThreshold>0</discardingThreshold>
        <appender-ref ref="TARGET"/>
    </appender>
    <root level="INFO"><appender-ref ref="ASYNC"/></root>
</configuration>
```

队列容量和丢弃策略按应用负载设置，以上数值只是配置示例。若使用普通 AsyncAppender，可改用 `%X{tl}` 输出日志事件的 MDC 快照，不要让消费线程重新从业务 ThreadLocal 取标签。

## 避免重复或缺失标签

- 消息前缀方式使用 TLog encoder/appender，并保留 `mdc-enable` 未设置或不启用；pattern 不再额外输出 `tl`。
- MDC 方式使用普通 encoder 和 `%X{tl}`，可设置 `tlog.mdc-enable=true`，避免其它 TLog 消息转换器再次追加。
- 在日志配置中启用 `TLogLogbackTTLMdcListener` 也会把模式切换为 MDC，因此 pattern 要包含 `%X{tl}`。

完整配置见示例工程 `tlog-example-log-logback-sync`、`-logback-async`、`-logback-mdc`、`-logback-ttl-mdc`。业务 `@Async` 和线程池的传播仍需按[线程池文档](/pages/a69e1d/)配置。
