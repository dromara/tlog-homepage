# logback与logstash的集成

`tlog-logstash-logback` 提供 `TLogLogstashLogbackProvider`，把 **日志事件快照中的 MDC** 写入 JSON。网络发送由 `logstash-logback-encoder` 的 appender 完成，不是 TLog 单独实现的 Logstash 客户端。

## 依赖选择

```xml
<dependency>
    <groupId>com.yomahub</groupId>
    <artifactId>tlog-logstash-logback</artifactId>
    <version>2.0.0</version>
</dependency>
```

应用还需显式声明 `net.logstash.logback:logstash-logback-encoder`，并选用与自己的 JDK、logback 和 Jackson 代际匹配的版本。该适配器当前签名使用 `com.fasterxml.jackson.core.JsonGenerator`（Jackson 2）；不能直接推断任意未来 encoder 或 Jackson 3 API 都兼容。

TLog 编译基线使用 encoder 6.6。下列是该 API 形式的配置示例，不是对 Boot 3/4 推荐固定使用旧 encoder 版本。现代环境须核对实际 encoder 的接口兼容性。

## logback 配置

```xml
<configuration>
    <appender name="LOGSTASH" class="net.logstash.logback.appender.LogstashTcpSocketAppender">
        <destination>127.0.0.1:9800</destination>
        <keepAliveDuration>5 minutes</keepAliveDuration>
        <encoder class="net.logstash.logback.encoder.LoggingEventCompositeJsonEncoder">
            <providers>
                <timestamp/>
                <logLevel/>
                <loggerName/>
                <threadName/>
                <message/>
                <stackTrace/>
                <provider class="com.yomahub.tlog.logstash.logback.TLogLogstashLogbackProvider"/>
            </providers>
        </encoder>
    </appender>
    <root level="INFO"><appender-ref ref="LOGSTASH"/></root>
</configuration>
```

provider 写入的是事件的全部 MDC 字段，包括 `tl`、`tlogTraceId`、`tlogSpanId` 及应用自己的 MDC。请让其它 JSON provider 与这些字段使用不冲突的名称。异步日志应保留事件 MDC 快照，不能在发送线程重新读取请求 ThreadLocal。

## Logstash 接收示例

```text
input {
  tcp {
    port => 9800
    codec => json_lines
  }
}
output {
  stdout { codec => rubydebug }
}
```

该模块针对 logback，不能把它作为 Log4j/Log4j2 appender 使用。新 demo 实际验证了 logback 异步事件 MDC，但**未启动 Logstash 服务端**；这里保留的是适配 API 与配置说明，部署前仍需验证你选择的 encoder、socket 输入及 JSON schema。验证范围见[兼容性说明](/guide/compatibility)。
