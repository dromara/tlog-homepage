# logback与logstash的集成

`tlog-logstash-logback` 提供 `TLogLogstashLogbackProvider`，把 **日志事件快照中的 MDC** 写入 JSON。网络发送由 `logstash-logback-encoder` 的 appender 完成，不是 TLog 单独实现的 Logstash 客户端。

## 依赖选择

```xml
<dependency>
    <groupId>com.yomahub</groupId>
    <artifactId>tlog-logstash-logback</artifactId>
    <version>2.0.0</version>
</dependency>
```

应用还需自己声明 `net.logstash.logback:logstash-logback-encoder`。TLog 以 encoder 6.6 编译，provider 使用 Jackson 2 的 `com.fasterxml.jackson.core.JsonGenerator`；基于 Jackson 3 的 encoder 版本不兼容。

本模块只负责把 MDC 写进 JSON。TLog 上下文仍由 starter 或其它 TLog 入口建立。

## logback 配置

```xml
<configuration>
    <appender name="LOGSTASH" class="net.logstash.logback.appender.LogstashTcpSocketAppender">
        <destination>127.0.0.1:9800</destination>
        <keepAliveDuration>5 minutes</keepAliveDuration>
        <encoder class="net.logstash.logback.encoder.LoggingEventCompositeJsonEncoder">
            <providers>
                <timestamp/>
                <logLevel/>
                <loggerName/>
                <threadName/>
                <message/>
                <stackTrace/>
                <provider class="com.yomahub.tlog.logstash.logback.TLogLogstashLogbackProvider"/>
            </providers>
        </encoder>
    </appender>
    <root level="INFO"><appender-ref ref="LOGSTASH"/></root>
</configuration>
```

provider 写入事件的全部 MDC 字段：TLog 的 `tl`、`tlogTraceId`、`tlogSpanId`、`currIp`、`preIp`、`preIvkHost`、`preIvkApp`，以及应用自己的 MDC。不要再配置 `<mdc/>` provider，否则 MDC 字段会输出两次。

## Logstash 接收示例

```text
input {
  tcp {
    port => 9800
    codec => json_lines
  }
}
output {
  stdout { codec => rubydebug }
}
```

该模块只支持 logback，不能用于 Log4j/Log4j2。完整示例见示例工程 `tlog-example-log-logstash`，它把日志经 TCP 发给真实的 Logstash 8.15，并检查收到的 JSON 含全部 TLog 字段。
