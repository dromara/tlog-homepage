# 项目特性

TLog 2.0 保留日志标签追踪的使用方式，更新了现代 Spring、日志和异步框架的适配。

| 能力 | 支持内容 |
| --- | --- |
| 日志关联 | traceId、层级 spanId、上下游信息和可配置标签模板 |
| 日志输出 | logback、Log4j2，以及旧 Log4j 适配器；通过配置文件或 MDC 输出 |
| Spring Boot | 同一套 starter 适配 Boot 2、3、4，自动选择 javax/jakarta Servlet Filter |
| HTTP / RPC | Servlet、WebFlux、Feign、Dubbo/Dubbox，以及对应 HTTP 客户端和网关适配 |
| 自动 HTTP 埋点 | 装饰容器中的 RestTemplate、WebClient.Builder、RestClient.Builder；RestClient 要求 Spring 6.1+ |
| 异步 | Spring 执行器自动装饰；`TLogExecutors.wrap` 覆盖外部 Executor、ExecutorService 和 ScheduledExecutorService |
| 响应式链路 | Reactor Context 隔离请求，在订阅和信号回调期间恢复 TLog 上下文 |
| 业务标签 | `@TLogAspect` 支持参数表达式、固定文本、连接符和自定义转换器 |
| 消息中间件 | Kafka、RabbitMQ 经消息 header 透传：Spring Kafka / Spring AMQP 自动装配，原生客户端一行接入；其它 MQ 使用消息体包装 |
| 任务 | Spring Scheduled、JDK Timer、Quartz、XXL-JOB 适配 |
| 扩展与开关 | 自定义 ID 生成器 Bean、分功能开关、响应头开关和 IDE 配置提示 |
| W3C 入站 | 没有 TLog traceId 时，尝试复用合法 `traceparent` 的 trace-id |

框架支持不等于任意依赖版本都已逐一测试。TLog 自身为 Java 8 字节码，应用运行 JDK 仍由所选 Spring Boot 和其它框架决定。完整测试矩阵和未覆盖的场景见[兼容性与验收](/guide/compatibility)。

新版本不再提供 javaagent、`AspectLogEnhance.enhance()` 或固定“0.01% 损耗”的承诺。线程池、响应式和日志异步队列的传播边界分别见[线程池](/pages/a69e1d/)、[WebFlux](/guide/webflux)和[日志适配](/pages/5223de/)。
