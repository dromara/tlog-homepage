# 对hutool-http的支持

TLog 2.0 保留 Hutool HTTP 请求拦截器。应用需要引入 `tlog-hutool-http:2.0.0` 和自己的 `cn.hutool:hutool-http`；客户端依赖不会由 TLog 强制传递。

当前可运行 demo 使用 Hutool **5.8.40**。以下代码采用请求拦截器 API，在请求发出前设置追踪头：

```java
import cn.hutool.http.HttpRequest;
import cn.hutool.http.HttpResponse;
import com.yomahub.tlog.hutoolhttp.TLogHutoolhttpInterceptor;

TLogHutoolhttpInterceptor tracing = new TLogHutoolhttpInterceptor();

try (HttpResponse response = HttpRequest.get("http://127.0.0.1:18081/api/context")
        .addRequestInterceptor(tracing)
        .timeout(5000)
        .execute()) {
    System.out.println(response.body());
}
```

`tracing` 可以复用。POST、表单等请求同样在 `HttpRequest` 上添加请求拦截器，不要只把它放到响应拦截阶段。关闭 `HttpResponse` 释放请求资源。

想让 `HttpUtil.get` 等静态方法也带上 TLog 头，可以全局注册一次：

```java
import cn.hutool.http.GlobalInterceptor;

GlobalInterceptor.INSTANCE.addRequestInterceptor(new TLogHutoolhttpInterceptor());
```

拦截器传播的是调用时的 TLog 上下文。纯 Java 程序如何建立上下文，见[纯 Java 客户端示例](/guide/examples#纯-java-客户端)。
