# 对forest的支持

通过 Forest 的请求拦截器安装 `TLogForestInterceptor`，可以把当前 TLog 上下文传到 HTTP 下游。TLog 不自动创建 Forest 客户端；在 Spring 与纯 Java 应用中都需要显式接入。

## 依赖与编程式调用

```xml
<dependency>
    <groupId>com.yomahub</groupId>
    <artifactId>tlog-forest</artifactId>
    <version>2.0.0</version>
</dependency>
<dependency>
    <groupId>com.dtflys.forest</groupId>
    <artifactId>forest-core</artifactId>
    <version>1.8.0</version>
</dependency>
```

```java
import com.dtflys.forest.config.ForestConfiguration;
import com.yomahub.tlog.forest.TLogForestInterceptor;

ForestConfiguration forest = ForestConfiguration.createConfiguration();
forest.setBackendName("okhttp3")
        .setConnectTimeout(5000)
        .setReadTimeout(5000)
        .setMaxRetryCount(0);

String result = forest.get("http://127.0.0.1:18081/api/context")
        .addInterceptor(new TLogForestInterceptor())
        .executeAsString();
```

`forest-core` 会传递引入 OkHttp 与 HttpClient 后端，无需另外声明。

## 声明式接口

```java
import com.dtflys.forest.annotation.Request;
import com.yomahub.tlog.forest.TLogForestInterceptor;

public interface ContextClient {
    @Request(url = "http://127.0.0.1:18081/api/context",
             interceptor = TLogForestInterceptor.class)
    String context();
}
```

用前面创建的 `forest` 配置生成客户端并调用：

```java
ContextClient client = forest.client(ContextClient.class);
String result = client.context();
```

想让所有请求都带上 TLog 拦截器，可以改为全局配置，接口上就不用再写 `interceptor`：

```java
import java.util.Collections;

forest.setInterceptors(Collections.singletonList(TLogForestInterceptor.class));
```

不要在同一个请求上重复添加 TLog 拦截器。

## 版本边界

推荐使用 **Forest 1.8.0**，示例工程用它在 JDK 8～25 上完成了验证。TLog 本身以 Forest 1.5.14 编译，但 1.5.14 的动态代理在 JDK 17+ 上不可用，运行在新 JDK 时请升级 Forest。

参见[可运行示例](/guide/examples)、[Forest 项目](https://github.com/dromara/forest)。
