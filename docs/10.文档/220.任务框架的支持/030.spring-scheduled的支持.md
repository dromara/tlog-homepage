# spring-scheduled的支持

对于普通同步 `@Scheduled` 方法，TLog 通过 Spring AOP 在每轮执行时建立新 trace，并在完成后清理。

## Spring Boot

任一 TLog starter 都已包含 `tlog-task`，只需正常启用 Spring 调度：

```java
@Configuration
@EnableScheduling
public class SchedulingConfiguration {
}

@Component
public class ReportTask {
    private static final Logger LOG = LoggerFactory.getLogger(ReportTask.class);

    @Scheduled(fixedDelay = 5000)
    public void generate() {
        LOG.info("生成本轮报告");
    }
}
```

注解分别来自 Spring 的 `context.annotation`、`scheduling.annotation` 和 `stereotype` 包，日志类型来自 SLF4J。TLog 不会替应用启用 `@EnableScheduling`。

```yaml
tlog:
  scheduled:
    enabled: true
```

该开关默认开启，设为 false 关闭 Spring Scheduled 的 TLog 自动切面；总开关关闭时同样不装配。不要把这个开关理解为停止业务调度。

## 普通 Spring 项目

引入 `com.yomahub:tlog-task:2.0.0`，在已经启用调度和 AspectJ 自动代理的 Spring 容器中注册：

```xml
<aop:aspectj-autoproxy/>
<task:annotation-driven/>
<bean class="com.yomahub.tlog.task.spring.SpringScheduledTaskAop"/>
```

`aop` 与 `task` 命名空间分别使用 Spring 对应 schema。

## 使用限制

- 只适用于同步方法。返回 `Mono`/`Flux` 的响应式定时方法，不保证每次订阅都有新 trace。
- 切面匹配单个 `@Scheduled` 注解。同一方法标注多个 `@Scheduled` 时，Java 会把它们编译成 `@Schedules`，切面不会生效。
- 方法内部再提交异步任务时，使用 Spring 管理的执行器（自动装饰）或 `TLogExecutors.wrap`，见[线程池](/pages/a69e1d/)。

完整示例见示例工程 `tlog-example-task-spring-scheduled`。
