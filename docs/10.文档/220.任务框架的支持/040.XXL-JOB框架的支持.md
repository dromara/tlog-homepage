# XXL-JOB框架的支持

TLog 通过 `TLogXxlJobAop` 对带 `@XxlJob` 的 Spring Bean 方法建立任务上下文。每次进入时创建 trace，业务方法完成或抛异常后清理。

## Spring Boot 接入

```xml
<dependency>
    <groupId>com.yomahub</groupId>
    <artifactId>tlog-xxljob-spring-boot-starter</artifactId>
    <version>2.0.0</version>
</dependency>
```

继续保留应用使用的 `xxl-job-core` 与执行器配置。TLog 的条件装配需要 XXL-JOB 注解及适配类存在，不会替你启动 admin、注册 executor 或创建调度任务。

```java
@Component
public class OrderJobHandler {
    private static final Logger LOG = LoggerFactory.getLogger(OrderJobHandler.class);

    @XxlJob("orderJob")
    public void execute() {
        LOG.info("处理本轮订单任务");
    }
}
```

`@XxlJob` 来自 `com.xxl.job.core.handler.annotation`。任务必须通过实际的 Spring 代理路径执行，才能触发这个 AOP 接入点。

## 非 Boot Spring 容器

引入 `com.yomahub:tlog-xxl-job:2.0.0`（注意模块名是 `xxl-job`，starter 名是 `xxljob`），在配置好 XXL-JOB 和 AspectJ 自动代理后注册：

```xml
<aop:aspectj-autoproxy/>
<bean class="com.yomahub.tlog.xxljob.aop.TLogXxlJobAop"/>
```

`tlog.enabled=false` 会关闭 Boot 自动装配；`tlog.scheduled.enabled` 专用于 Spring `@Scheduled`，不是 XXL-JOB 调度开关。手工声明的非 Boot Bean 仍由应用自行管理。

完整示例见示例工程 `tlog-example-task-xxljob`，它由真实的 XXL-JOB 调度中心（2.3.0）触发执行器。调度中心需要 Docker，建议用[一键验收](/guide/examples#一键验收)运行。
