# Quartz框架的支持

TLog 保留 Spring Quartz 适配类 `TLogQuartzJobBean`。它继承 Spring 的 `QuartzJobBean`，在每次执行入口建立 trace，并在 finally 中清理。

所有 TLog starter 都已包含 `tlog-task`；非 Boot 项目单独引入 `com.yomahub:tlog-task:2.0.0`。应用还需自己声明 `org.quartz-scheduler:quartz` 和 `org.springframework:spring-context-support`（TLog 以 quartz 2.3.2 编译）。TLog 不负责创建 scheduler、注册 JobDetail/Trigger 或配置 Quartz 集群。

```java
import com.yomahub.tlog.task.quartz.TLogQuartzJobBean;
import org.quartz.JobExecutionContext;
import org.quartz.JobExecutionException;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

public class OrderJob extends TLogQuartzJobBean {
    private static final Logger LOG = LoggerFactory.getLogger(OrderJob.class);

    @Override
    public void executeTask(JobExecutionContext context) throws JobExecutionException {
        String batch = context.getMergedJobDataMap().getString("batch");
        LOG.info("执行批次 {}", batch);
    }
}
```

将 `OrderJob` 按 Quartz 的常规方式注册为任务。重写 `executeTask`，保留父类的入口与清理流程。TLog 不替应用处理任务重试、错过触发时间或业务幂等。

完整示例见示例工程 `tlog-example-task-quartz`，运行方法见[可运行示例](/guide/examples#日志框架、定时任务与业务标签)。验证只覆盖单节点内存调度，没有覆盖 Quartz 集群模式。
