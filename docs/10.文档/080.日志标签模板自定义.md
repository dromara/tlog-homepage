# 日志标签模板自定义

默认完整标签为 `<$spanId><$traceId>`。可以在 Spring Boot 配置中调整格式：

```yaml
tlog:
  pattern: '[$preApp][$preIp][$spanId][$traceId]'
```

| 占位符 | 含义 |
| --- | --- |
| `$preApp` | 上游应用名称 |
| `$preHost` | 上游主机名 |
| `$preIp` | 上游 IP |
| `$currIp` | 当前节点 IP |
| `$spanId` | 当前节点的层级 spanId |
| `$traceId` | 当前请求的 traceId |

例如上游为 `order-service`，当前 span 为 `0.1`，可得到：

```text
[order-service][10.0.0.8][0.1][demo-request-001]
```

缺失或空白的字段显示为 `NONE`；空白模板通过配置初始化时保留默认模板。模板不会改变传播头名称或 spanId 的生成规则。

采用 MDC 时，`%X{tl}` 读取这份完整标签；`%X{tlogTraceId}` 等独立字段不会因为模板变化而改名。纯 Java 应用可在开始处理请求前调用 `TLogLabelGenerator.setLabelPattern(...)`，该设置是进程级配置，不应按请求切换。

业务参数标签使用另一个方法级配置 `@TLogAspect(pattern = "[{}]")`，与这里的全局模板不同，见[业务标签](/pages/9c287d/)。
