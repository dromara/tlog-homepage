# dubbo & dubbox

本页讨论**非 Spring Boot 的普通 Spring 容器**。如果使用 Boot，优先选择对应 starter，不要再重复声明自动配置已经提供的 Bean。这里的“Spring 项目”不表示已经支持 GraalVM Native Image。

## RPC 依赖

| RPC 框架 | TLog 模块 |
| --- | --- |
| Apache Dubbo | `com.yomahub:tlog-dubbo:2.0.0` |
| Alibaba Dubbo / Dubbox | `com.yomahub:tlog-dubbox:2.0.0` |

保留项目自己的 RPC 框架和日志依赖。TLog 的 RPC Filter 通过 Dubbo SPI 自动激活，不需要额外配置：

| SPI 名称 | 作用 | 生效端 |
| --- | --- | --- |
| `tlogDubboFilter` | 传递 traceId / spanId | provider 和 consumer |
| `tlogDubboInvokeTimeFilter` | 打印调用参数和耗时（需开启 `enableInvokeTimePrint`） | provider |

需要排除时，可在 Dubbo 配置中使用 `filter="-tlogDubboFilter"`。

## Spring 基础配置

```xml
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xmlns:aop="http://www.springframework.org/schema/aop"
       xsi:schemaLocation="
         http://www.springframework.org/schema/beans https://www.springframework.org/schema/beans/spring-beans.xsd
         http://www.springframework.org/schema/aop https://www.springframework.org/schema/aop/spring-aop.xsd">
    <bean id="tlogSpringAware" class="com.yomahub.tlog.spring.TLogSpringAware"/>
    <bean class="com.yomahub.tlog.spring.TLogPropertyInit" depends-on="tlogSpringAware">
        <property name="pattern" value="&lt;$spanId&gt;&lt;$traceId&gt;"/>
    </bean>
    <!-- 使用 @TLogAspect 业务标签时启用 -->
    <aop:aspectj-autoproxy/>
    <bean class="com.yomahub.tlog.core.aop.AspectLogAop"/>
</beans>
```

如果同一应用还有 HTTP 入口，再按[Servlet 说明](/pages/432802/)配置 Filter。MVC 拦截器 `TLogWebInterceptor` 只支持 javax，Jakarta 环境请使用 `TLogJakartaServletFilter`。

## 示例

示例工程 `tlog-example-dubbo-provider` / `-consumer`（Apache Dubbo 2.7 和 3.3）与 `tlog-example-dubbox-provider` / `-consumer`（Dubbox 2.8.4）都是直连调用，不需要注册中心，运行方法见[可运行示例](/guide/examples#webflux、gateway-与-dubbo)。
