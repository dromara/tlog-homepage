# SpringCloud的Openfeign

Spring Boot + OpenFeign 使用 `tlog-feign-spring-boot-starter:2.0.0`，条件满足时自动注册 `TLogFeignFilter`。应用仍需提供匹配 Boot/Cloud 版本的 OpenFeign starter，并正常启用、扫描自己的 FeignClient。

## 非 Boot 容器或手工 Feign

对于普通 Spring 项目，在创建 Feign 客户端时明确安装请求拦截器；仅声明一个 Bean 不保证任意手工构造的 `Feign.Builder` 都会自动使用它：

```java
import com.yomahub.tlog.feign.filter.TLogFeignFilter;
import feign.Feign;
import feign.RequestLine;

public interface ContextApi {
    @RequestLine("GET /api/context")
    String context();
}

ContextApi client = Feign.builder()
        .requestInterceptor(new TLogFeignFilter())
        .target(ContextApi.class, "http://127.0.0.1:18081");
String response = client.context();
```

声明 `tlog-feign:2.0.0` 与你的 Feign 依赖。调用时必须已有上下文；该请求拦截器传播当前 trace，并为下游生成子 span。

如果需要由现有 OpenFeign 基础设施收集 Spring Bean，可声明：

```xml
<bean class="com.yomahub.tlog.feign.filter.TLogFeignFilter"/>
```

是否收集、如何绑定到每个 client 由所用 Feign 集成负责。TLog 业务标签切面、属性初始化和 HTTP 服务端入口是独立事项，分别见[Spring 基础配置](/pages/d81b62/)、[其他配置](/pages/8110af/)与[Servlet](/pages/432802/)。

新 HTTP demo 已实际验证 OpenFeign 网络请求和上下文；Boot/Cloud 组合以[示例矩阵](/guide/examples)为准，不混用不同代际的 Cloud starter。
