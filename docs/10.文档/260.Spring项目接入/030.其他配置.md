# 其他配置

普通 Spring 容器不会自动读取全部 Boot `tlog.*` 配置。可以显式声明 `TLogSpringAware` 与 `TLogPropertyInit`，并保证初始化顺序：

```xml
<bean id="tlogSpringAware" class="com.yomahub.tlog.spring.TLogSpringAware"/>
<bean id="tlogPropertyInit"
      class="com.yomahub.tlog.spring.TLogPropertyInit"
      depends-on="tlogSpringAware">
    <property name="pattern" value="[$preApp][$preHost][$preIp][$spanId][$traceId]"/>
    <property name="enableInvokeTimePrint" value="false"/>
    <property name="mdcEnable" value="true"/>
</bean>
```

应用名的配置方式见下文[应用名、总开关与 W3C](#应用名、总开关与-w3c)。

## 自定义生成器 Bean

```xml
<bean id="customTraceIdGenerator" class="com.example.trace.CustomTraceIdGenerator"/>
<bean class="com.yomahub.tlog.spring.TLogPropertyInit" depends-on="tlogSpringAware">
    <property name="idGeneratorInstance" ref="customTraceIdGenerator"/>
</bean>
```

上面是替换属性初始化 Bean 的写法，不要与前一个 `tlogPropertyInit` 同时声明两套。生成器实现见[自定义 TraceId](/pages/6d41f7/)。

## 应用名、总开关与 W3C

容器启动时，`TLogSpringAware` 从 Spring Environment 读取 `spring.application.name` 和 `tlog.enabled`（未配置时分别为 `NONE`、`true`），并覆盖此前通过 `TLogRuntime.setAppName` / `setEnabled` 设置的值。所以在 Spring 应用里，请把这两项写进 Environment。例如在 `application.properties` 中写：

```properties
spring.application.name=order-service
tlog.enabled=true
```

再用 `@PropertySource` 加载它：

```java
@Configuration
@PropertySource("classpath:application.properties")
public class AppConfig {
}
```

`<context:property-placeholder>` 只做占位符替换，不会把属性放进 Environment，TLog 读不到。

`TLogRuntime.setAppName` / `setEnabled` 只适用于没有 Spring 容器的纯 Java 程序。

W3C `traceparent` 入站复用默认开启。需要关闭时，在应用初始化时调用：

```java
import com.yomahub.tlog.core.rpc.TLogRPCHandler;

TLogRPCHandler.setW3cTraceContextEnabled(false);
```

W3C 支持的是入站 traceId 复用，不会导出 tracing span。

## 线程池

Boot 的 `web.enabled`、`http-client.enabled`、`async.enabled` 等条件装配开关不会管理你在 XML 中手工声明的 Bean。普通 Spring 的执行器需要自己设置 TaskDecorator：

```java
import com.yomahub.tlog.core.thread.TLogExecutors;

ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
executor.setTaskDecorator(TLogExecutors::wrap);
```

非 Spring 线程池使用 `TLogExecutors.wrap(executorService)`，见[线程池](/pages/a69e1d/)。

日志端继续使用配置文件适配器或 MDC `%X{tl}`。2.0 已移除 javaagent 和 `AspectLogEnhance.enhance()`，不要把旧字节码注入方式与这些配置混用。版本和验证边界见[兼容性说明](/guide/compatibility)。
