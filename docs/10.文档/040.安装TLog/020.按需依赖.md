# 按需依赖

按应用用到的框架选择 starter，多个 starter 可以组合。以下模块均使用 `com.yomahub` groupId 和 `2.0.0` 版本。

| 模块 | 使用场景 |
| --- | --- |
| `tlog-web-spring-boot-starter` | Servlet 或普通 WebFlux 入口；包含常用 HTTP 客户端以及 Kafka、RabbitMQ 适配模块 |
| `tlog-dubbo-spring-boot-starter` | Apache Dubbo |
| `tlog-dubbox-spring-boot-starter` | Dubbox |
| `tlog-feign-spring-boot-starter` | Spring Cloud OpenFeign |
| `tlog-gateway-spring-boot-starter` | Spring Cloud Gateway |
| `tlog-soul-spring-boot-starter` | Soul 网关 |
| `tlog-shenyu-spring-boot-starter` | ShenYu 网关 |
| `tlog-xxljob-spring-boot-starter` | XXL-JOB |

例如，一个有 Servlet 入口并使用 OpenFeign 的应用：

```xml
<dependency>
    <groupId>com.yomahub</groupId>
    <artifactId>tlog-web-spring-boot-starter</artifactId>
    <version>2.0.0</version>
</dependency>
<dependency>
    <groupId>com.yomahub</groupId>
    <artifactId>tlog-feign-spring-boot-starter</artifactId>
    <version>2.0.0</version>
</dependency>
```

这些依赖提供适配代码，不代替应用的 Web starter、Dubbo、Feign、日志实现或 HTTP 客户端。日志实现仍由应用选定；不要为了 TLog 同时加入多套 SLF4J binding。

普通 WebFlux 使用 Web starter 中的 WebFlux 适配；Gateway 使用专用 Gateway starter。不必为 Boot 3/4 改成另一组 jakarta 坐标。

Dubbo、Dubbox、Feign、XXL-JOB starter 同样带有 `tlog-kafka` 和 `tlog-rabbitmq`；Gateway、Soul、ShenYu starter 不带。它们只在 classpath 中存在 Spring Kafka 或 Spring AMQP 时生效，不会替应用引入 MQ 客户端。

非 Boot 或纯 Java 项目可直接使用 `tlog-core`、`tlog-okhttp`、`tlog-httpclient`、`tlog-kafka`、`tlog-rabbitmq` 等实现模块，并显式安装相应组件。接入边界见[兼容性与验收](/guide/compatibility)。
