# 全量依赖

## Spring Boot 应用

```xml
<dependency>
    <groupId>com.yomahub</groupId>
    <artifactId>tlog-all-spring-boot-starter</artifactId>
    <version>2.0.0</version>
</dependency>
```

该 starter 聚合 TLog 的 Web、WebFlux、Dubbo/Dubbox、Feign、Spring Cloud Gateway、HTTP 客户端、Kafka、RabbitMQ、定时任务和 XXL-JOB 适配模块（Soul、ShenYu 网关需单独引入对应 starter）。自动配置会根据 classpath 和开关决定是否生效；它不会为应用安装所有 RPC 服务端、HTTP 客户端或日志实现。

继续保留应用自己的 Spring Boot Web/WebFlux、日志和所用客户端依赖。只需要部分适配时，可使用[按需依赖](/pages/9bca79/)。

## 非 Boot 应用

```xml
<dependency>
    <groupId>com.yomahub</groupId>
    <artifactId>tlog-all</artifactId>
    <version>2.0.0</version>
</dependency>
```

`tlog-all` 聚合 Dubbo/Dubbox、Servlet、定时任务、Kafka、RabbitMQ 和常用 HTTP 客户端的实现模块，不包含 Feign、网关和 XXL-JOB 模块，也不提供 Boot 自动配置。可以改为只引入所需的单个实现模块。

非 Boot 项目需要自己注册组件和拦截器，见[Spring 项目接入](/pages/d81b62/)和[其他配置](/pages/8110af/)。

## 构建与运行条件

TLog 自身使用 `--release 8` 编译，源码构建要求 JDK 17+。Boot 3/4 等现代框架的运行 JDK 基线仍由这些框架决定。所有 TLog 模块应统一为 2.0.0，不混用 1.x；Boot 2/3/4 使用同一套坐标，不需要 `-jakarta` 后缀。

加入依赖后还要完成[日志配置](/pages/5223de/)。完整流程见[快速开始](/guide/quick-start)。
