# Javaagent 接入已移除

TLog 2.0 不再提供 `tlog-agent` 模块或 javaagent 接入。旧版 agent 不应与 2.0 依赖混用。

迁移时加入应用所需的 TLog starter，删除 JVM 中指向 `tlog-agent.jar` 的 `-javaagent` 参数，再配置日志输出。logback 应用可以使用普通 encoder 和 `%X{tl}`；详细步骤见[快速开始](/guide/quick-start)和[升级指南](/guide/upgrade)。

原接入依赖对日志类的字节码修改，受类加载时机、Spring Boot fat jar 和现代 JDK 强封装影响。2.0 使用日志框架扩展点，不再要求通过 JVM 开放参数维持旧增强逻辑。
