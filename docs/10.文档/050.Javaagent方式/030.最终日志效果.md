# 迁移后如何验证日志效果

此页面保留旧链接；TLog 2.0 的日志效果通过配置文件实现，不需要 javaagent。

给服务 A 的 HTTP 入口发送一个已知 traceId，再由 A 调用已接入 TLog 的服务 B：

```sh
curl -H 'tlogTraceId: demo-request-001' http://localhost:8080/trace-demo
```

假设 A 是根入口、B 是第一次出站调用，两端日志示意为：

```text
<0><demo-request-001> 服务 A 开始处理请求
<0.1><demo-request-001> 服务 B 处理下游调用
<0><demo-request-001> 服务 A 收到结果
```

A 的当前 span 仍是 `0`；子 span `0.1` 写入发往 B 的请求，由 B 的入口采用。需要同时核对真实日志前缀、MDC 与传播头，不能只看接口回传了哪个 ID。

可重复运行的跨进程 HTTP、Dubbo、网关和 MQ 验证见[示例工程](/guide/examples)，规则见[SpanId](/pages/595a3c/)。
