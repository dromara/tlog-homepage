# 删除旧 Javaagent 启动参数

如果部署脚本、容器环境变量或 IDE 启动项中仍有下面的参数，升级到 2.0 时将它删除：

```text
-javaagent:/your_path/tlog-agent.jar
```

这是一项需要移除的旧配置，不是 2.0 的启动命令。2.0 不提供可替换下载的 `tlog-agent.jar`。

普通 Spring Boot fat jar 保持常规启动方式：

```sh
java -jar application.jar
```

启动前完成[依赖安装](/pages/9bca79/)与[日志配置](/pages/5223de/)。通过携带 `tlogTraceId` 的真实请求确认响应头和日志标签，步骤见[快速开始](/guide/quick-start)。
