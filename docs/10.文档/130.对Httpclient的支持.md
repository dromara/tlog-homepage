# 对Httpclient的支持

TLog 2.0 通过请求拦截器把当前 traceId、下游 spanId 和调用方信息写入 HTTP 请求头。Apache HttpClient 4 与 5 使用不同接口，需要分别安装对应适配器；这两类客户端不会因声明成 Spring Bean 就自动装饰。

## 依赖

```xml
<dependency>
    <groupId>com.yomahub</groupId>
    <artifactId>tlog-httpclient</artifactId>
    <version>2.0.0</version>
</dependency>
```

应用还需声明实际使用的客户端：4.x 为 `org.apache.httpcomponents:httpclient`，5.x 为 `org.apache.httpcomponents.client5:httpclient5`。TLog 将它们作为 provided/optional 编译依赖，不会强制带入运行时。

## HttpClient 4

```java
import com.yomahub.tlog.httpclient.TLogHttpClientInterceptor;
import org.apache.http.client.methods.CloseableHttpResponse;
import org.apache.http.client.methods.HttpGet;
import org.apache.http.impl.client.CloseableHttpClient;
import org.apache.http.impl.client.HttpClients;
import org.apache.http.util.EntityUtils;

try (CloseableHttpClient client = HttpClients.custom()
        .addInterceptorLast(new TLogHttpClientInterceptor())
        .build();
     CloseableHttpResponse response = client.execute(
        new HttpGet("http://127.0.0.1:18081/api/context"))) {
    System.out.println(EntityUtils.toString(response.getEntity(), "UTF-8"));
}
```

## HttpClient 5

```java
import com.yomahub.tlog.httpclient.TLogHttpClient5Interceptor;
import org.apache.hc.client5.http.classic.methods.HttpGet;
import org.apache.hc.client5.http.impl.classic.CloseableHttpClient;
import org.apache.hc.client5.http.impl.classic.CloseableHttpResponse;
import org.apache.hc.client5.http.impl.classic.HttpClients;
import org.apache.hc.core5.http.io.entity.EntityUtils;

try (CloseableHttpClient client = HttpClients.custom()
        .addRequestInterceptorLast(new TLogHttpClient5Interceptor())
        .build();
     CloseableHttpResponse response = client.execute(
        new HttpGet("http://127.0.0.1:18081/api/context"))) {
    System.out.println(EntityUtils.toString(response.getEntity(), "UTF-8"));
}
```

生产应用通常复用连接池和客户端，在应用关闭时再释放；上面用 try-with-resources 展示完整的资源生命周期。

拦截器只传播已有上下文。来自 TLog Web/RPC 入口的调用已经有上下文；纯 Java 主动发起链路时，需要先建立并在 finally 中清理。完整代码与五种客户端的真实网络验证见[可运行示例](/guide/examples#纯-java-客户端)。
