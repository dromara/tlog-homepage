# 字节码注入方式已移除

TLog 2.0 已删除 `com.yomahub.tlog.core.enhance.bytes.*`，包括 `AspectLogEnhance`。升级后不能继续调用 `AspectLogEnhance.enhance()`，也不需要等待或抢占日志框架类加载时机。

保留应用自己的日志实现，通过 TLog encoder/layout/converter 或 MDC 输出标签。Spring Boot 入口由 starter 自动配置；非 Boot 应用按相应框架文档注册组件。

下一步：[移除旧增强代码](/pages/a62510/)、[日志适配](/pages/5223de/)、[完整升级指南](/guide/upgrade)。
