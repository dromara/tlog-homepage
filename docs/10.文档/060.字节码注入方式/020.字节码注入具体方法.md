# 移除旧字节码增强代码

升级到 2.0 时，删除启动类中的旧增强调用及其 import：

```java
// 从旧项目中删除这一行；2.0 已无此类。
static { AspectLogEnhance.enhance(); }
```

应用的启动类保持常规写法：

```java
@SpringBootApplication
public class Application {
    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```

然后按日志实现配置 [logback](/pages/f62a84/)、[Log4j2](/pages/8d5538/) 或已有的 [Log4j](/pages/a48c8e/) 适配。也可以用 MDC `%X{tl}` 输出完整标签。

如果升级后出现 `AspectLogEnhance` 找不到类或编译失败，应迁移上述代码，不要把 1.x 的 core/agent jar 加回 2.0 classpath。其它公开 API 的兼容边界见[升级指南](/guide/upgrade)。
