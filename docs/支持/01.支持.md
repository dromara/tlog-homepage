# 支持 TLog

TLog 是 MIT 许可的开源项目。你可以通过使用反馈、问题复现、文档修订和代码贡献帮助项目继续改进。

## 参与项目

- 在 [GitHub](https://github.com/dromara/TLog) 或 [Gitee](https://gitee.com/dromara/TLog) 关注项目。
- 提交问题时附上 TLog、JDK、Spring Boot、日志框架版本和最小复现。
- 分享可复现的集成场景，帮助完善兼容性验证。
- [加入社区讨论](/pages/73c2c3/)，交流实践经验。
