2.0.0 ​

2.0 是面向 Spring Boot 2、3、4 的大版本升级。兼容范围与验收结果见兼容性与验证范围。

  • 使用同一套 Java 8 字节码产物与 starter 坐标，适配 Boot 2/3/4；Servlet 自动选择 javax/jakarta，处理 Spring 7 API 差异。
  • 移除 javaagent 与 AspectLogEnhance.enhance() 字节码接入；保留日志配置文件适配器与 MDC。
  • 修复表单编码、异常后的上下文泄漏、可选模块缺失启动失败、MDC/线程池传播和自定义生成器初始化顺序。
  • 自动装饰 Spring 管理的 ThreadPoolTaskExecutor / SimpleAsyncTaskExecutor，并组合已有 TaskDecorator；补齐 MVC Callable、ASYNC/ERROR 重派发。
  • 自动装饰容器中的 RestTemplate、WebClient.Builder、RestClient.Builder；纯 Java 客户端通过 Spring 无关的运行配置工作。
  • WebFlux 改用 Reactor Context 与命名 hook；普通入口和网关转发分离，首个 WebClient 子 span 正确为 0.1。
  • 新增 tlog-kafka、tlog-rabbitmq：经消息 header 透传上下文。Spring Kafka / Spring AMQP 自动装配，保留用户已有的拦截器、post processor 和重试 advice；原生客户端各一行接入。开关为 tlog.kafka.enabled、tlog.rabbitmq.enabled。
  • 增加入站 W3C traceId 复用、细粒度开关、ID 生成器 Bean 扩展与配置提示。
  • 改用 fastjson2，移除字节码增强和未使用依赖；客户端、Servlet、日志等适配目标由应用选择运行版本。

库 158 项测试通过。示例工程的一键验收在 Boot 2.7 / 3.5 / 4.0 与 JDK 8–25 的 10 组组合上完整通过（每组 78 或 79 项断言），包含 HTTP、WebFlux、Gateway、Dubbo、Dubbox、Kafka、RabbitMQ、定时任务、XXL-JOB、各日志框架和纯 Java 客户端。具体版本和未覆盖项见兼容性与验证范围，复现方法见可运行示例。
